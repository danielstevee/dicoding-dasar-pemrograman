# dicoding-dasar-pemrograman
Dokumentasi dan latihan pembelajaran kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang Software dari Dicoding.

**21 Agustus 2026**<br>
Belajar kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang Software.

* Belajar memahami kebutuhan aplikasi dari sisi pengguna dan spesifikasi teknis.
* Belajar menganalisis kebutuhan aplikasi sebagai dasar dalam pengembangan perangkat lunak.
* Belajar membuat requirement aplikasi berdasarkan kebutuhan pengguna dan spesifikasi teknis.

**22 Agustus 2026**<br>
Melanjutkan kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang Software.

* Belajar membuat perencanaan modifikasi aplikasi menggunakan requirement dan diagram alur (flowchart).
* Belajar konsep dasar pemrograman seperti variabel, tipe data, logika komputer, dan pseudocode.
* Berlatih menulis kode pertama menggunakan JavaScript ES6.
* Belajar dasar HTML5 dan CSS3 untuk memodifikasi antarmuka aplikasi.

**23 Agustus 2026**<br>
Menyelesaikan kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang Software. (Progres 100%)

* Belajar dokumentasi pemrograman dan pengembangan perangkat lunak.
* Belajar pengarsipan perangkat lunak, penulisan gaya kode, komentar pada kode, dan dokumentasi teknis aplikasi.
* Mengerjakan ujian akhir untuk mengevaluasi pemahaman selama pembelajaran.
* Mendapatkan sertifikat kelulusan kelas Memulai Dasar Pemrograman untuk Menjadi Pengembang Software.
